# GIDAVTO

Сайт компании по перевозке автомобилей. React + Vite + GSAP / ScrollTrigger. Сохранены оригинальная вступительная погрузка, пять подготовленных изображений и векторный логотип. Добавлены подбор перевозки, маршрут, этапы работы, вопросы и форма заявки. Изображения и шрифты не запрашиваются с внешних сайтов.

## Продолжение страницы

- Семь типов кузова используют фотографические растровые изображения из чата вместо нарисованных автомобилей. Переключение кнопками, стрелками клавиатуры, соседними стрелками и горизонтальным жестом на сенсорном экране.
- Четыре типа транспорта имеют отдельные фотографические изображения из чата: открытый и закрытый автовоз, эвакуатор с платформой и малый автовоз. Для «Помогите выбрать» показаны три варианта вместе. Доступность вариантов редактируется флагами `enabled` в `src/config.js`. Это не утверждение о собственном автопарке компании.
- Автомобиль, состояние, примечания, транспорт, города, дата и контактные поля хранятся в одном состоянии React. Черновик сохраняется через `sessionStorage` только в текущей вкладке; при недоступности хранилища форма продолжает работать.
- Итог маршрута обновляется сразу. Обмен городов не сбрасывает остальные поля.
- Валидация городов, имени, телефона и необязательной даты. Ошибки показаны рядом с полями, первое ошибочное поле получает фокус.
- Настоящей интеграции отправки нет. «Запросить стоимость» формирует редактируемый через исходные поля текст; «Скопировать заявку» копирует его в буфер. При недоступности Clipboard API текст выделяется для ручного копирования. Сообщения об отправке, сроки доставки и вымышленные контакты не используются.
- Калькулятор немедленно считает по вручную введённому километражу, ставке и доплатам. Все слагаемые и причины показаны отдельно и включаются в заявку. Компания не предоставляла утверждённые тарифы; никакие ставки или расстояния не выдумываются. Подробнее — `PRICING.md`.
- Компактная навигация появляется после вступления. Закреплённая сцена имеет приоритет пересчёта перед нижними анимациями. Якоря обновляют геометрию перед переходом, прямые ссылки восстанавливаются после загрузки изображений и создания pin-spacer.
- Кастомный курсор обновляется через `requestAnimationFrame`, не использует React state на каждом движении и не перехватывает клики. В текстовых полях, на сенсорных устройствах и при reduced motion остаётся обычный указатель.
- Этапы работы доступны целиком сразу; прокрутка заполняет линию и выделяет текущий этап. FAQ управляется кнопками с `aria-expanded`. Новые секции не закрепляются.

Изображения являются сгенерированными фотографическими иллюстрациями категорий, а не подтверждением автопарка. SVG используется только для показа растровой фотографии с контурной маской. Тексты вариантов, этапов и FAQ находятся в `src/config.js`; происхождение изображений описано в `PHOTO_ASSETS.md`.

## Открыть локально

Нужен Node.js 20.19+ или 22.12+.

```powershell
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/ и прокручивайте страницу. Обратная прокрутка возвращает все действия назад.

```powershell
npm run check  # геометрия колёс, поверхности и шарнира
npm run build  # готовая статическая сборка в dist/
npm run preview
```

После сборки папку `dist` можно разместить на статическом хостинге. Открывать `index.html` двойным щелчком через `file://` не следует: для модулей нужен HTTP-сервер.

## Как устроена анимация

- Одна закреплённая секция на высоту окна, одна основная timeline, пять высот окна прокрутки, scrub 0.45 секунды.
- 0–8%: подсказка исчезает, логотип немного уменьшается и поднимается.
- 8–30%, 30–50%, 50–70%: оранжевый, серебристый и синий автомобили.
- 70–80%: подъём рампы; 80–82%: закрытая платформа перед стартом.
- 82–100%: плавный разгон и полный выезд.
- `src/geometry.js` задаёт общую систему координат. Положение обоих колёс рассчитывается по поверхности с учётом радиуса шин и неизменной колёсной базы. Положение и угол кузова следуют из этих точек.
- Автомобили отсекаются SVG clipPath у заднего проёма и скрываются за непрозрачной стенкой. Opacity автомобилей не анимируется.
- Рампа, стенка, маска и связанные элементы находятся в одном родительском узле автопоезда.
- Изображения декодируются до создания ScrollTrigger. Геометрия хранится в SVG viewBox, а ScrollTrigger пересчитывает длину при изменении размера окна.
- На узком экране камера кадрирует зону погрузки: ожидающие машины уходят за левую границу, часть автопоезда — за правую. Масштаб сохраняет различимость автомобилей. Камера не движется при прокрутке.
- `prefers-reduced-motion: reduce` оставляет статичный начальный кадр без длинного закрепления.
- GSAP-контексты и медиа-обработчики очищаются при размонтировании React.

## Исходные изображения

Все пять исходных PNG имеют настоящий альфа-канал. Подготовлены WebP с обрезанными прозрачными полями, с сохранением пропорций и альфа-канала. Цветовая маска чёрного не применялась. Измерения и исходные имена — в `asset-report.json`.

Колёса сохранены в составе исходных фотографических вырезок: отдельных чистых слоёв шин, дисков и неподвижных суппортов в исходниках нет. Для независимого вращения колёс нужны дополнительно подготовленные слои; условные круги поверх фотографий не используются.

Логотип создан отдельными SVG-контурами и не зависит от загрузки шрифта. Для текста используется системный Arial / Helvetica. Отдельный растровый макет не был приложен, композиция следует текстовому заданию.

## Проверка

В браузере проверены начальный кадр, три последовательных погрузки, маскирование оранжевой машины на рампе, закрытие, выезд, финал на максимальной прокрутке, быстрый возврат и мобильная версия 390×844. На одной и той же позиции 20% прямой и обратной прокрутки координаты автомобиля совпали. В остановленной сцене прогресс остался на 20%. Ошибок и предупреждений в консоли при проверке не обнаружено. Горизонтальная прокрутка на телефоне отсутствует.

Тринадцать автоматических проверок проходят: три проверки геометрии, четыре проверки заявки и шесть проверок калькулятора. Покрыты 881 положение на рампе для каждого автомобиля, контакт с поверхностью и постоянная колёсная база; совпадение рампы с дорогой и шарниром; полное скрытие и выезд; состав заявки, некорректные поля, восстановление черновика и итог маршрута. Режим reduced motion реализован через media query; переключение системной настройки в браузерной проверке не выполнялось.

Паттерны ScrollTrigger и очистки React сверены с официальной документацией: https://gsap.com/docs/v3/Plugins/ScrollTrigger/ и https://gsap.com/resources/React/.
